description: Start (or resume) the current Hookline version with the lecturer
---

1. Read `AGENTS.md`, then `supervision/STATUS.md`.
2. Read the brief for the version named in `STATUS.md` (`supervision/briefs/vX.Y.md`). If it's missing, tell the learner to ask the supervisor for `brief vX.Y` and stop.
3. If the review for this version says POLISH or REDO, read `supervision/reviews/vX.Y.md` and run a polish round on its "Must fix" list instead of starting fresh.
4. Make sure the version branch from the brief exists and is checked out. Create it from `main` if not.
5. Set `STATUS.md` state to `in-progress` (skip if it already is).
6. Begin at step 1 (Check in) of "How every session works" in `AGENTS.md`. If resuming, read the last learning-log entry and pick up where it stopped.
