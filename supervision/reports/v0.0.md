## What was taught
- **What a backend is:** OS process listening on a port, guarding the trust boundary, and coordinating state across services.
- **Request journey:** Traced DNS → TCP → TLS 1.3 → Reverse Proxy → Go Process → DB, mapping latency & failure points.
- **Hookline's job:** Webhook inversion (Hookline is the HTTP client) and the post-office model.
- **The method:** Go standard library first, learning logs, and recording architectural decisions.
